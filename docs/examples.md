# Examples

These examples reproduce selected workflows from the [libigl tutorial](https://libigl.github.io/tutorial/). They require the compiled `compas_libigl` extensions and, for visualisation, `compas-viewer`.

The gallery pages show committed screenshots and source code. They are not executed during the headless documentation build.

- [Boundary loops](examples/example_boundaries.md)
- [Curvature](examples/example_curvature.md)
- [Geodesic distance](examples/example_geodistance.md)
- [Ray-mesh intersections](examples/example_intersections.md)
- [Isolines](examples/example_isolines.md)
- [Mapping](examples/example_mapping.md)
- [Mass matrix](examples/example_massmatrix.md)
- [Meshing](examples/example_meshing.md)
- [Mesh parametrisation](examples/example_parametrisation.md)
- [Planarisation](examples/example_planarize.md)

The source scripts and data are maintained in the [compas_libigl repository](https://github.com/compas-dev/compas_libigl).
